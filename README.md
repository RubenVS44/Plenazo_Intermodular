# Gestion, reservas y disponibilidad - Bolera 🎳
Este proyecto consiste en el desarrollo de una aplicación para la gestión de reservas de pistas, control de disponibilidad en tiempo real y administración de servicios adicionales para una bolera.
## 👥 Integrantes del Equipo
* **Rubén Vazquez** - **Base de datos y servidor** -> Diseña la BD (E/R, normalización, script SQL) y se encarga del despliegue en AWS y la conexión SSH.
* **Pablo Ventero** - **Programacion** -> Desarrolla la lógica de la aplicación: conexión con la BD, excepciones, logs y tests unitarios.
* **Iván Rodriguez** - **Interfaz y documentación** -> Diseña las pantallas de la aplicación, genera el Javadoc, la vista HTML y prepara la memoria.
## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java / HTML / CSS
* **Base de Datos:** SQL (MySQL)
* **Control de Versiones:** Git y GitHub
## 📌 Funcionalidades Principales del Sistema
* **Gestión y reservas de Pistas:** Control del estado de las pistas (Disponibles, Ocupadas, En Mantenimiento) y posibilidad de reserva.
* **Consulta de resultados:** Posibilidad de consultar los resultados de las partidas.
* **Gestion de judadores:** Consulta de los jugadores participantes.
* **Roles de Usuario:** 
    * *Cliente:* Registra sus reservas y consulta disponibilidad.
    * *Administrador:* Gestión total de pistas, horarios y tarifas.
